# لوحة منتجات اليابان — نسخة مستضافة

الرابط الحيّ: https://riyadsmart-hub.github.io/rs-panel-1f6bb3c9/
كلمة المرور في `../.panel-key` (خارج المستودع، غير مرفوعة).

## ما هي
صفحة واحدة مستقلّة: كل منتج يُورَّد من اليابان، بألوانه ومقاساته و**أرخص مصدر لكل مقاس**
برابطه (راكوتين · أمازون · هيمارايا · Gallery-2 · مواقع العلامات)، وتبويب لإضافة منتج جديد.

## لماذا كلمة مرور
مستودع GitHub Pages المجاني **عامّ**، والبيانات فيها تكاليفك وهوامشك. فالحمولة كلها
**مضغوطة ثم مشفّرة AES-256-GCM** بمفتاح مشتقّ من كلمة المرور (PBKDF2، ٢٥٠ ألف دورة).
بلا الكلمة لا يرى الزائر إلا نصّاً مشفّراً. والصفحة `noindex` ومعها `robots.txt` مانع.

## التحديث بعد أي تغيير في البيانات
```bash
node build.mjs && git add -A && git commit -m "تحديث البيانات" && git push
```
`build.mjs` يقرأ لوحة الأرتيفاكت المبنيّة ويعيد التشفير بنفس كلمة المرور من `../.panel-key`.
